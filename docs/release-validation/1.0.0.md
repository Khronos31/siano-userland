siano-ts --instance qa-fixed-s1ud --runtime-dir /tmp/3pr/s1rt \

### Linux x86_64 static/musl 配布candidateの限定受信

source `57d457f924776b006df6b3716d4fb4b6b85b671d` / Core `154e9de7b813cee3cd9db07f22795a4a9e9ae833` の`packaged-linux` artifact `12583353326`（package SHA-256 `0f6cee49cfcfd5271ae72478937322f4da682fa1432df9e8ac724df2bed341c2`、manifestは`build_libc=musl`, `linkage=static`）をPX-S1UDで8秒→600秒→事後短T27の順に取得した。

10分capture command:

```sh
siano-ts --runtime-dir <runtime> --instance musl-siano --receiver 0 \
  -c T27 -t 600 -o /dev/null
```

実時間601.935秒、client exit 0。ただしclientに統計行がなく、10分runのpacket/error値は未計測であり0とは扱わない。事後短TSと`tsanalyze --normalized`はいずれもexit 0、TSID 32736、PAT/PMT・A/Vあり、invalid sync/transport error/PID discontinuity 0。daemon通常終了exit 0、runtime socketとUSB ownerなし。

これはLinux x86_64 static配布archiveのT27単一受信に限る結果である。最大同時受信、3波、受信中status/制御、物理挿抜を行った全archive回帰ではない。

別の物理USB試験では受信中の抜去後52.486秒まで自然終了しなかった。通常SIGINTでclient/daemonはexit 0、daemon logに`LIBUSB_ERROR_IO`が残った。再接続後、新daemonで8秒のT27受信はTS error 0で完了した。詳細は[`initial-model-checks.md`](initial-model-checks.md)へ記録する。Sianoには衛星/CARD/LNB機能がないため該当試験は対象外。

各OS/ABIのfinal candidate archive回帰と最終candidate由来の2時間・全channel結果は未認定。全channel10秒取得はLinux x86_64代表機に限り、各binaryで行う短時間回帰と分ける。

## 候補checkpointと確認状況

2026-10-25時点の採用mainは `57d457f924776b006df6b3716d4fb4b6b85b671d`、Core pinは `154e9de7b813cee3cd9db07f22795a4a9e9ae833`。このcheckpointに対する1.0.0 final candidate archiveのnative matrix結果は未記録である。

この版の`.github/workflows/release.yml`は`workflow_dispatch`をtriggerとし、tag eventによる自動build/releaseは未定義である。この動線の実装状況は本版のrelease gate結果に含め、未対応のtag commandは作らない。

Core pin変更時にはSiano source `0be9f14bda5238988240c6e0a2e8224a639ccd04` とCore `154e9de7b813cee3cd9db07f22795a4a9e9ae833` でLinux device-free buildを行った。`sianod`、`sianoctl`、`siano-ts` と既存runtime proof群が成功し、候補版CLIで次の不支持system確認も行った。

```sh
siano-ts --freq 1000000000 --system ISDB-S --slot 1 --instance smoke
```

結果はexit 3、`unsupported broadcast system (ISDB-T only)`。この確認はpin用build branchのLinux binaryであり、final 1.0.0 candidate artifactやnative Windows/実機matrixの結果ではない。binary SHA-256、1.0.0 candidate run/artifact、final-candidate OS別実測は未記録。

## 1.0.0結果の記録

各実施行に製品source SHA、Core SHA、candidate run/artifact/archive SHA、native OS/architecture、機種とUSB selector、実command、物理操作、TS/counter、終了値、process/runtime cleanupを記録する。履歴候補や他OSの結果をfinal candidateへ読み替えず、未実施行は理由とともに `未実施` / `未認定` とする。今回の文書変更ではsource・CI・実機を検証していない。

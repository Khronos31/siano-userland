# Siano 1.0.0 検証記録

候補取得、device-free gate、受信・USB切断・cleanupの再利用手順は [`../release-validation.md`](../release-validation.md) を正本とする。本書には1.0.0固有matrixと、現在確認できているsource/Core・検証範囲だけを記録する。

## 1.0.0 初回matrix

この時間/targetは1.0.0だけに適用する。代表Linux x86_64は2時間、macOS arm64とWindows x86_64は各30分、その他の全配布binaryは各10分。全7 binaryをnative OS/architectureで短時間回帰し、全実地域地上波channelを各10秒raw TS取得する。Sianoには衛星/CARD/LNB機能がないため、それらの試験は対象外。各機種自体の一度以上2時間qualificationとmajor versionごとの全OS/architecture短TSは別項目として記録する。地上波channel labelとRF値は実施前に現地計画から固定する。

## 候補checkpointと確認状況

2026-10-25時点の採用mainは `57d457f924776b006df6b3716d4fb4b6b85b671d`、Core pinは `154e9de7b813cee3cd9db07f22795a4a9e9ae833`。このcheckpointに対する1.0.0 final candidate archiveのnative matrix結果は未記録である。

Core pin変更時にはSiano source `0be9f14bda5238988240c6e0a2e8224a639ccd04` とCore `154e9de7b813cee3cd9db07f22795a4a9e9ae833` でLinux device-free buildを行った。`sianod`、`sianoctl`、`siano-ts` と既存runtime proof群が成功し、候補版CLIで次の不支持system確認も行った。

```sh
siano-ts --freq 1000000000 --system ISDB-S --slot 1 --instance smoke
```

結果はexit 3、`unsupported broadcast system (ISDB-T only)`。この確認はpin用build branchのLinux binaryであり、final 1.0.0 candidate artifactやnative Windows/実機matrixの結果ではない。binary SHA-256、1.0.0 candidate run/artifact、final-candidate OS別実測は未記録。

## 1.0.0結果の記録

各実施行に製品source SHA、Core SHA、candidate run/artifact/archive SHA、native OS/architecture、機種とUSB selector、実command、物理操作、TS/counter、終了値、process/runtime cleanupを記録する。履歴候補や他OSの結果をfinal candidateへ読み替えず、未実施行は理由とともに `未実施` / `未認定` とする。今回の文書変更ではsource・CI・実機を検証していない。

# 1.0.0 リリース前検証結果

この文書は固定1.0.0 candidateの結果記録用。今回記録するT13以外の結果欄は`未実施 / 未認定`から開始する。正本`docs/release-validation.md`の手順・期待値・状態語彙に従い、未実施・未達・失敗をPASSへ読み替えない。

## 適用範囲

- **通常release:** 正本T00–T15と共通頻度表の毎release項目を適用する。代表Linux x86_64 glibcで標準機種2時間連続TS、全配布binaryごとのnative OS/ABI短時間回帰、毎release T15を記録する。
- **初回/major:** 正本T13のmajor項目を追加する。代表Linux機の標準機種（PX-S1UD）で対象無料channel全件を各10秒。macOS/Windows各archiveは30分、残りOS/ABI各archiveは10分連続TS。必要時項目も該当条件を通す。
- **必要に応じて:** 正本T11/T12と変更機能に対する機種×OS/ABI確認を行い、適用理由または仕様に基づくN/A理由を記録する。
- ソークは一定時間以上の**連続TS取得**。通常release代表Linuxの2時間runが同じcandidate/modelで連続してmajor Linux 10分条件も満たした場合は同じrunを両方へ参照できる。
- 正本の状態語彙は`今回再検証` / `継承` / `未認定` / `対象外`。この雛形の未実施は未認定でありPASSではない。`対象外`は製品仕様上の対象外だけに使う。別source/binaryの結果を本candidateへ転用しない。
- 機種そのものの初回確認は機種別記録へ残す。この版別結果で代替しない。
